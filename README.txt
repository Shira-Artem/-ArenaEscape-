ArenaEscape — Версия IMPROVED v2
=================================

ИЗМЕНЕНИЯ В ЭТОЙ ВЕРСИИ:
─────────────────────────────────────────────────────────────────

1. ОРУЖИЕ — ТЕПЕРЬ НОРМАЛЬНО БЬЁТ
   • Меч: кулдаун 0.25с (было 0.40с), удержание ЛКМ = автоатака
   • Топор: кулдаун 0.80с (было 1.15с)
   • Лук: кулдаун 1.0с (было 1.50с), скорость стрелы 40 (было 35)
   • Радиус OverlapSphere увеличен 1.2→1.8, дальность лучей шире
   • 9 направлений попадания вместо 7

2. МЕНЮ ПОБЕДЫ (WIN SCREEN)
   • Появляется когда убит FinalBoss (Великий Вождь в зоне 4)
   • Анимированное появление с золотой рамкой и пульсацией
   • Показывает: Очки, Убито врагов, Монеты
   • Кнопки: Заново / Главное меню
   • Финальный босс имеет 250 HP и при смерти даёт супер-взрыв

3. МЕНЮ СМЕРТИ (GAME OVER)
   • Полностью переработан — анимированный экран
   • Красная виньетка по краям экрана
   • Пульсирующий заголовок с черепом
   • Кнопки Рестарт / Меню появляются после анимации
   • Показывает итоговые очки

УСТАНОВКА:
──────────
1. Открыть Unity Hub → Add → выбрать эту папку
2. Unity 6 (6000.x) — обязательно
3. После открытия: Window → AI → Navigation → Bake (для NavMesh)
4. Edit → Project Settings → Player → Input Manager (Old)
5. Запустить сцену Game.unity

УПРАВЛЕНИЕ:
───────────
WASD — движение          Shift — бег
Мышь — камера            Пробел — прыжок
ЛКМ — атака              ПКМ — смена меч/топор (или прицел лука)
1/2/3 или Tab — смена оружия
Escape — пауза
